#### Como usar

##### Requisitos

Para executarmos os comandos para baixar e abrir o projeto precisamos de:

- git
- python

Para clonar esse repositório, use o comando no terminal do seu computador:

```bash
git clone https://github.com/samuelrodriguesbrito1/e-commerce-livros
```

Para abrir no seu navegador há diversos meios, o meio mais recomendado para esse projeto é abrir um servidor com o comando:

```python
python -m http.server 8000
```

Após isso, você pode abrir no seu navegador com a seguinte url:

```text
http://localhost:8000/
```

Com o navegador aberto na url, você pode acessar as quatro telas usando o hash do navegador:

- `#/buscar` - Para tela de buscar
- `#/resultado` - Para tela de resultado da busca
- `#/cadastro` - Para tela de cadastro
- `#/inativar` - Para tela de inativar

No seu navegador, você pode colocar essa url para ver a tela de resultado por exemplo:

```text
http://localhost:8000/#/resultado
```
